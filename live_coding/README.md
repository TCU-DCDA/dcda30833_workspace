# Live-Coding Plans

Per-session teaching plans for the **hands-on technique weeks**, taught by
building a sketch *with the class* in the p5.js Web Editor rather than from a
slide deck. (Conceptual framing weeks use the decks in `slide_decks/`.)

Each plan is built around **what you build live**, not bullet points, and
follows the course rhythm: open → live build → discussion → live build →
studio → exit. The goal on screen is discovery — predict before running, keep
instructive mistakes, and re-run to show the *range* one system produces.

Every teaching week is covered. [week_03_randomness.md](week_03_randomness.md)
was the model.

Two shapes recur. **Technique weeks** (3, 5, 7, 9, 10, 12, 14) open with a hook,
build twice, and hand the room into studio on a lab due that Wednesday. **Project
weeks** (6, 8, 11, 13) shorten the builds to protect studio time and carry that
project's required in-class **System Autopsy** beat. Week 15 is neither — studio
and a rehearsal critique for the exhibition.

Weeks 1, 2 and 4 are covered by the decks in `slide_decks/`. See
`context/build_status.md` for why the rest are live-coded rather than decked.
