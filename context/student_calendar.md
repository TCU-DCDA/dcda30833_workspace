# DCDA 30833 — Course Schedule

Spring 2027 · Creative Coding for the Humanities · MW, 80 minutes

**How the week runs.** A week's technique is taught Monday; the lab on it is due
that Wednesday, and a second lab (where a week has one) the following Monday.
Projects are due Wednesday. Nothing is ever due at the session that teaches it.

**How a unit runs.** Lab (build the grammar) → System Autopsy (take a precedent
apart) → Project (synthesize).

**Publish continuously.** Every lab and project is pushed to GitHub *and* live on
GitHub Pages at its own URL, from Week 1 on.

> This calendar represents current course plans. Plans may change to enhance
> learning opportunities; any changes will be announced in class and posted here.
